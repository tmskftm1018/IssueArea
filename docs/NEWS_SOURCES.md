## 준비할 자료

연결할 출처별 공식 RSS/API 주소와 이용허락 기록이 필요합니다. 제목 표시, 메타데이터 저장, 원문 링크, 비상업·상업 이용, 출처 표기 조건을 구분해 확인합니다. RSS 수집에는 보통 별도 API 키가 필요 없지만 인증형 API는 제공자가 발급한 자격증명이 필요할 수 있습니다.

API 키를 발급받았다는 사실만으로 언론사 콘텐츠 재표시 권한을 승인하지 않습니다. API 이용약관과 콘텐츠 이용 범위를 함께 확인합니다. 승인된 API를 선택하면 어댑터와 비밀 환경변수 설정을 추가합니다.

README의 `app.source_registry` 명령을 사용합니다. `docs/source-review.example.json`은 기본 미검토 양식이며 승인을 대신하지 않습니다. 조건부 이용허락은 실제 충족한 조건과 근거를 `notes`에 기록합니다. 검토 내용 변경 시 출처는 자동 비활성화되며 별도의 `enable` 명령이 필요합니다.
