내 손안에 서울 전체 피드는 `https://mediahub.seoul.go.kr/news/rss/`입니다. 안내 페이지에는 카테고리별 RSS와 함께 RSS 리더 구독 용도가 설명되어 있습니다. 개별 콘텐츠의 공공누리 유형·표시 권한을 확인하기 전까지는 후보만 등록하고 자동 수집 및 노출을 하지 않습니다.

전국 정부·지자체 보도자료를 하나의 공공 피드/API로 통합 제공하는 공식 출처는 이번 조사에서 확인되지 않았습니다. 정책브리핑은 RSS 종료를 공지했고, 공공데이터포털 검색에서 찾은 정책뉴스 API는 성평등가족부 등 제공 기관별 서비스입니다. 행정안전부 보도자료 RSS는 `https://www.mois.go.kr/gpms/view/jsp/rss/rss.jsp?ctxCd=1012`이며 공식 RSS 안내가 보도자료 피드로 분류합니다. 행정안전부 저작권 정책은 공공누리 표시가 있는 자료의 자유 이용과 출처 표시를 허용하고, 표시 없는 자료는 사전 협의를 요구합니다. 2026-10-02자 보도자료 페이지는 보도자료 저작물을 공공누리 1유형으로 명시했고, 제1유형은 상업 이용도 허용하되 출처 및 가능한 경우 원문 링크를 표시하도록 합니다. 이에 보도자료 RSS만 조건부 검토·활성화했습니다. 다른 자료 종류나 본문·사진·첨부파일까지 이용 허락된 것으로 확대 해석하지 않습니다.

2026-10-07에 행정안전부 보도자료 RSS를 다시 확인하고 ID 6에 권리 검토 기록을 적용했습니다. RSS는 HTTP 200과 27개 항목을 반환했습니다. RSS에 게시 시각이 누락된 항목은 기사 원문의 `등록일`을 확인해 보강합니다. 날짜만 확인된 기사는 상대 시각 대신 날짜를 표시하고, 날짜 범위와 겹치는 선택 기간에 포함합니다. 날짜 확인이 실패한 기사는 보강 전까지 최근 뉴스에서 숨깁니다. 지역 분류는 제목에서 확인되는 실제 지명만 지도 지역에 연결합니다. `이태원참사` 표기를 서울 별칭에 추가해 기존 기사를 재분류한 뒤 4건이 지역 기사, 23건이 전국 단위 보도자료로 분류됐습니다. 행정안전부의 중앙부처 피드에서 지역명을 확인할 수 없는 자료는 `전국` 범위로 표시하고 지도상의 특정 지역에 억지로 배정하지 않습니다. IssueArea에는 제목·출처·원문 URL·게시일만 저장하며, 본문·사진·첨부파일은 가져오지 않습니다.

시·군·구 이름으로 들어오는 기사도 16개 지도 권역에 연결하도록 `backend/app/localities.py`에 별칭을 정리했습니다. 별칭 목록은 [행정안전부 2026년 지방자치단체 행정구역 및 인구 현황](https://mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000055&nttId=128138)을 기준으로 관리합니다. 단독 `동구`, `중구`, `서구`, `남구`, `북구`, `강서구`, `고성군`처럼 여러 시·도에 반복되는 이름은 잘못된 지역에 붙지 않도록 생략하고, 제목에 시·도 문맥이 있는 경우에만 연결합니다. API와 수집기가 시작될 때 저장된 기사도 새 별칭으로 재분류합니다. 지도는 현재 광역 권역 단위이며 구·군·시 경계 확대는 별도의 행정구역 경계 데이터 적용 단계입니다.

국가데이터처도 RSS 안내에서 공지사항·보도자료·언론보도 설명 피드를 각각 제공합니다. 보도자료 후보 URL은 `https://mods.go.kr/board.es?mid=a10301010000&bid=a103010100&act=rss`입니다. 국가데이터처 저작권 정책은 기관이 저작재산권을 보유하거나 권리자 동의를 얻어 공공누리 표시를 붙인 저작물의 이용을 허용하고, 유형별 출처 표시 등 조건을 준수하도록 안내합니다. 제목·출처·원문 URL·작성 시각만 저장하더라도 피드 전체를 일괄 허용으로 간주하지 않고 비활성 후보로 둡니다.

2026-09-30에 해당 피드를 일회성으로 확인했습니다(HTTP 200, XML, RSS 해석 정상, 10개 항목, 제목·원문 링크·게시 시각 포함). 최근 예시는 산업활동동향과 지역내총생산 통계 발표로 일반 현장 뉴스보다 통계·정책 공지 성격이 강합니다. 당시 표본 두 건은 이용조건이 “첨부파일 안의 공공누리유형”에 따른다고 표시했습니다. 2026-10-07 현재 공식 저작권 정책은 제1유형을 출처표시 조건의 상업 이용 가능 유형으로, 제2유형은 상업 이용 금지, 제3유형은 변경 금지, 제4유형은 둘 다 금지한다고 설명합니다. 개별 보도자료에서도 2026년 8월 온라인쇼핑동향은 제4유형, 2026년 9월 소비자물가동향은 제1유형으로 확인되어 게시물별 필터가 필요합니다. 이에 전용 어댑터는 공식 RSS를 받고 원문 HTML에서 KOGL 도메인 링크에 명시된 유형을 확인해 제1유형만 허용합니다. 제2~4유형은 제외하고, 라이선스가 없거나 읽을 수 없는 새 항목도 보류합니다. 본문·사진·첨부파일은 저장하지 않습니다.

전용 어댑터는 RSS 간격을 최소 30분으로 제한하고 보도자료 원문 주소만 확인합니다. 명시적 라이선스가 제2~4유형으로 바뀌면 이미 저장된 해당 항목을 삭제합니다. HTML 구조가 바뀌어 라이선스 링크를 읽지 못하면 신규 수집을 중단합니다. 현재 제1유형만 수집하는 출처 심사 기록은 `docs/source-review-mods.json`이며, 첫 연결 명령은 [MODS 설정 안내](MODS_SETUP.md)를 참고합니다.

2026-10-07 실제 연결 검증: 기존 비활성 후보 ID 7을 전용 어댑터로 안전하게 전환하고, 제1유형만 허용하는 조건부 검토 후 활성화했습니다. 공식 RSS 10건을 확인해 제1유형 3건을 로컬 DB에 저장했고, 명시적인 비제1유형 2건은 제외했습니다. 나머지 5건은 명확한 제1유형 증거를 얻지 못해 보류했습니다. 수집 결과는 성공이며 현재 3건은 전국 단위 보도자료로 표시됩니다. 하루 요청이나 API 키는 사용하지 않습니다.

## 준비할 자료

연결할 출처별 공식 RSS/API 주소와 이용허락 기록이 필요합니다. 제목 표시, 메타데이터 저장, 원문 링크, 비상업·상업 이용, 출처 표기 조건을 구분해 확인합니다. RSS 수집에는 보통 별도 API 키가 필요 없지만 인증형 API는 제공자가 발급한 자격증명이 필요할 수 있습니다.

API 키를 발급받았다는 사실만으로 언론사 콘텐츠 재표시 권한을 승인하지 않습니다. API 이용약관과 콘텐츠 이용 범위를 함께 확인합니다. 승인된 API를 선택하면 어댑터와 비밀 환경변수 설정을 추가합니다.
