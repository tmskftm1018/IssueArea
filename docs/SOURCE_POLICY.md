# 뉴스 출처 등록 정책

기본 저장소는 자체 생성한 개발용 Demo만 활성화합니다. RSS가 공개되어 있다는 사실만으로 재사용 권한을 판단하지 않습니다.

운영자는 다음 내용을 확인하고 Source Registry에 기록합니다.

- 출처명과 공식 Feed/API URL
- 공식 제공 여부, 이용약관 URL, 확인 날짜
- 제목 표시와 메타데이터 저장 허용 여부
- 상업 이용 허용 여부
- 출처 표기·원문 링크 조건과 기타 제한
- 조건부 허용인 경우 이 서비스가 해당 조건을 충족하는지 여부

`rights_status`는 `unreviewed`, `allowed`, `conditional`, `prohibited`입니다. 검토 전에는 `enabled=false`로 등록합니다. `conditional`은 운영자가 조건을 검토하고 충족한 경우에만 활성화합니다. 상업 운영은 `APP_USAGE_MODE=commercial`로 설정합니다. 수집기는 상업 이용 허용이 없는 출처를 거부합니다.

등록 기능은 관리자 CLI 전용이며 사용자 입력 RSS URL API는 없습니다. Feed 주소는 운영자가 신뢰하는 공용 HTTP(S) 주소를 직접 등록해야 합니다. 배포 환경에서 외부 요청의 사설망 접근을 방화벽으로 제한하세요.

`python -m app.source_registry`는 `add`, `list`, `review`, `enable`, `disable` 명령을 제공합니다. 검토 파일은 엄격한 JSON 스키마를 따르고 확인 시각에 시간대를 포함해야 합니다. 미래 확인 시각, 기본 사설 IP·localhost 주소, 중복 피드, 미검토 활성화를 거부합니다. 이 URL 검사는 DNS 재바인딩이나 리다이렉트까지 차단하는 네트워크 방화벽을 대체하지 않습니다.

검토 수정은 해당 출처를 자동으로 비활성화합니다. 비활성·권리 미승인·금지 출처의 기존 기사도 조회와 지도 집계에서 제외하며, `DEMO_MODE=false`에서는 저장되어 있는 Demo 기사도 제외합니다. 출처 상태 명령은 토큰이 포함될 수 있는 Feed URL을 출력하지 않습니다.

기사 본문·이미지·AI 요약을 저장하지 않습니다. 제목, 출처, 원문 URL, 시각과 분류 메타데이터만 저장합니다. 본 문서는 이용허락을 대신하지 않습니다.
