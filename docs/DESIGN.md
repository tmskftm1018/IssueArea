# IssueArea 디자인 방향

설계 대상은 대한민국 지역별 뉴스를 탐색하는 과제용 사이트입니다. 핵심 동작은 지도에서 지역을 고르고 기사의 제목을 눌러 원문을 읽는 것입니다.

## 토큰

- 배경: #F3F6F4. 지도의 정보가 묻히지 않는 밝은 바탕.
- 본문: #1D302C. 제목과 본문에 쓰는 짙은 녹회색.
- 보조 본문: #5E716B. 출처와 시각에 사용.
- 동작·선택: #116349. 선택한 지역과 활성 필터에 사용.
- 선택 배경: #E7F2EB. 활성 상태와 기사 수 배지.
- 경계: #DCE5E0. 서로 다른 작업 영역을 구분.

서체는 한국어 시스템 고딕을 사용합니다. 추가 다운로드 없이 한국어 제목을 안정적으로 표시하고, 제목 32px/27px, 섹션 17px, 기사 제목 17px/16px의 위계를 적용합니다.

## 레이아웃

모든 정보는 왼쪽 정렬합니다. 상단 안내는 짧게 유지하고 지도·기사 목록에 공간을 배분합니다.

```text
브랜드                                      지도 탐색 / 뉴스 목록
지역으로 읽는 오늘의 뉴스                          최근 수집 시각
검색                                              조회 기간
관심 주제
선택한 지역                                      필터 초기화
지역 지도                         최신 뉴스 목록
지역 선택                         제목 / 출처 / 게시 시각
```

작은 화면은 지도와 기사 목록을 세로로 배치하고 상단 바로가기로 이동할 수 있게 합니다. 장식용 영문 라벨과 과도한 그림자를 제거하고, 모서리와 테두리는 필터·지도·목록의 구분에 사용합니다. 지도가 가장 눈에 띄는 요소가 되게 하고 기사는 읽기 편한 간격을 유지합니다.

## 적용 스킬과 소스

frontend-design으로 화면의 목적과 위계를 정하고, web-design-guidelines로 입력창 이름·초점·키보드 이동·모바일 터치·긴 제목 처리를 점검했습니다. Lucide의 네 아이콘을 Icon 컴포넌트에 적용했습니다. 원본 라이선스는 `web/public/icons/lucide/LICENSE`에 보관합니다.
